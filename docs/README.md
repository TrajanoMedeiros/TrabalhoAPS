# Docs

Este diretorio concentra documentacao complementar do monorepo Saldoo.

## Documentos Principais

- `../README.md`: onboarding, setup, scripts, stack, variaveis e fluxos.
- `../backend/README.md`: notas especificas da API Laravel.
- `../frontend/README.md`: notas especificas da aplicacao React.
- `../docker/docker-compose.yml`: infraestrutura local.

## Diretrizes De Manutencao

- Documentar novas decisoes tecnicas quando elas mudarem setup, arquitetura ou deploy.
- Manter comandos de execucao sincronizados com `package.json`.
- Preferir documentacao curta, verificavel e orientada a onboarding.
- Nao duplicar detalhes extensos quando o README da raiz ja cobrir o fluxo completo.
